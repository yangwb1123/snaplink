## Gate decision

The design document was reviewed at the same revision it now stands; **zero findings were incorporated**. The two convergent Highs (self-contradictory `Allow` SQL; non-transactional `SeedIfEmpty`) are still verbatim in the text and would, if implemented literally, either disable the shared limiter or deadlock the boot path. SRE's three launch blockers (limiter-error counter, backup/restore naming, load acceptance) and QA's two High test-surface gaps are absent from the design and its test plan. Nothing here is dismissible: every blocking item is test-pinnable and cheap to fix in the design text before implementation; none requires re-architecture.

Amendments required before the implementation stage opens: (1) pin the `Allow` latest-window lookup (PK-prefix, no `window_start` predicate) with a row-count assertion and staggered-clock two-replica test; (2) state same-connection `SeedIfEmpty` execution with rollback-leaves-zero and racing-admin-Put tests; (3) add `window_end` index (or bounded sweep) to migration v2; (4) add limiter-error/fail-open metric counter and correct the `/readyz` claim; (5) resolve delete-last-policy semantics (marker row or documented caveat); (6) nil-db guards for all store methods incl. `Allow`/`SeedIfEmpty`; (7) add the lifecycle-wiring and sqlite-backed HTTP admin CRUD tests to the test plan; (8) name the backup unit and restore semantics; (9) add B2 load acceptance as a design gate; (10) reject memory-mode DSNs; (11) correct the "no golden file" rationale; (12) specify the `allow()` early-return guard and clock-skew direction documentation.

VERDICT: FAIL - Design unchanged since reviews; blocking: Allow window-lookup SQL still self-contradictory (limiter never denies), SeedIfEmpty "Put each seed" still invites MaxOpenConns(1) deadlock, no limiter-error metric or /readyz write-wedge correction, unindexed window_end sweep under write lock, delete-last-policy re-seed unaddressed, closed-store panic unguarded, lifecycle/HTTP-admin test gaps, no backup/DR naming, no load-acceptance gate.
