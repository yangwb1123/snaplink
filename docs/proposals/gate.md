## Blocking issues (unresolved, not dismissed with reasons)

The design was never revised in response to any review, and items 1–3 each contain text that directly contradicts the reviewers' required fixes:

1. **NaN/Inf validation hole (决策 2).** The exact flawed formulation `RequireRenewAfter < 0 || > 1` remains. Two independent compiled probes (pinned goccy v1.19.2) confirm `.nan` parses and propagates to a MinInt64 threshold → every matching token introspects `{active:false}`. Defeats the design's own headline hard-error contract. Required: `!(f > 0 && f <= 1)` at both `Validate` seams + fail-safe `RenewExceeded`/`RenewAt` + NaN/Inf test rows.
2. **TTL dual-plumbing contradiction (决策 11 vs 决策 3).** "When sqlite is used" leaves the memory backend (stock-wired today) on the 1h Server-field default — a `token_ttl: 30m` + `max_ttl: 2h` deployment still widens default clients to 1h, and a missed wiring is silently wrong instead of known-legacy. Required: unconditional `WithTokenPolicyDefaultTTL(b.cfg.Server.TokenTTL)` at the single call site feeding `build_signing_issuers.go`, Server field default **0**, cmd-level single-source assertion + rootcov non-1h test on both backends.
3. **Memory-backend permanent divergence (决策 7/8).** Multi-replica memory fleets (valid topology, the *only* way to run policies today) get a write API whose writes never converge; no `haCoherenceIssues` entry, no loud log, not in the unsupported-topology list — contradicting the design's own convergence guarantees. Required: extend `haCoherenceIssues` (or refuse/unmount writes for per-pod stores under HA), explicit memory=single-replica-writes contract, memory-case two-server test.
4. **SRE launch blockers absent from the design:** bus-degradation alert, snapshot-age gauge + write-error counter + explicit `/readyz` decision, and the restore/backup contract (SRE F3). Deferral to "后续" with no owner is not a dismissal.
5. **Mediums that must be settled before implementation:** `Get` slice-aliasing contract (deep-copy, QA F5/Arch A4); atomic single-transaction seed (elevate from optional to required, Arch A5); audit-event product decision (Prot M2/Arch A6); perf F-P1 lock-scope constraint (pin "build outside lock, swap pointer" in 决策 6/10).

VERDICT: FAIL - three probe/code-verified High findings are unresolved and un-dismissed in the design (NaN validation hole in 决策 2; TTL wiring conditional on sqlite with a masking 1h default in 决策 11/3; writable admin on the memory backend with no convergence or HA guard in 决策 7/8), plus the SRE launch blockers (alerting, observability, restore contract) are deferred without owner, and four Medium design contracts (Get aliasing, atomic seed, audit trail, refresh lock scope) are unspecified. The design must be revised to incorporate these before the implementation stage.
