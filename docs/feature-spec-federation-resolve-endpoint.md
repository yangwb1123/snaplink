# Feature Spec: OpenID Federation 1.0 §8.3 Resolve Endpoint

> Generated by: Architect Agent | For: Implement Agent | Verified by: Reviewer Agent

## 1. Goal

Add the OpenID Federation 1.0 §8.3 **Federation Resolve endpoint** (`GET /.well-known/openid-federation-resolve`) that resolves a full trust chain for a given entity identifier and returns it as a JSON array of signed Entity Statements (JWS strings). This completes the federation trust-chain resolution story so a relying party or intermediate can fetch a pre-verified chain from this server acting as a **Trust Anchor** or **Intermediate**.

**Why now**: The `TrustChainResolver` (trust_chain_assemble.go + trust_chain_climb.go) already implements full chain climbing — entity config fetch → subordinate statement fetch → recursion up to anchor → signature re-validation. What's missing is the **HTTP endpoint** that exposes this resolution as a service, which is required for:

- OpenID Federation 1.0 certification (OIDF认证)
- Self-federated / trust-anchor deployment stories (自建联邦)
- eduGAIN / research / government federation participation
- Enabling SPs to resolve RP trust chains without implementing the full resolver

- [x] O1: Discovery doc advertises the new endpoint correctly

- [x] O3: Cache-Control: no-store on error responses

### Federation-Specific
- [x] F1: `GET /.well-known/openid-federation-resolve?sub=<entity_id>` returns a JSON object with `{ "chain": ["jws1", "jws2", ...] }` 
- [x] F2: Missing `sub` parameter → 400 `invalid_request`
- [x] F3: Unknown/unresolvable entity → 404 `not_found` (stable error, no enumeration)
- [x] F4: Disabled resolver (no trust anchors) → 404 `not_found` (same as unresolvable, oracle-safe)
- [x] F5: Chain is ordered leaf-first (leaf Entity Config → subordinate statements → anchor Entity Config)
- [x] F6: Each JWS in the chain is a signed Entity Statement (typ: entity-statement+jwt)
- [x] F7: Discovery doc's `federation_resolve_endpoint` is advertised in `federation_entity` metadata when trust anchors are configured
- [x] F8: Response is `Content-Type: application/json`
- [x] F9: Cache-Control: no-store (chain is per-request credential metadata, not public)
