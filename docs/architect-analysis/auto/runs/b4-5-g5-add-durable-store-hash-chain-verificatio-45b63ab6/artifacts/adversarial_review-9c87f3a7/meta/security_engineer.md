Verdicts on the five questions:

1. **Per-page Limit + offset paging vs. the clamp trap — CONFIRMED, with two residual holes.** `NormalizedLimit` (auditspi/query.go:86-92) maps ≤0→100, >1000→1000, and the sqlite sink bakes it into `LIMIT` (sqlite/query.go:82-84). The correct loop shape already exists in `auditexport.pageAll` (auditexport.go:168: pinned `Limit = MaxQueryLimit`, EOF on `len(page) < 1000`) and must be copied verbatim. **Hole A**: the design reuses `--limit` whose default is 10 000 (auditverify/main.go:37) — a `--dsn` run over a >10k-event store would silently verify a clean prefix: the clamp trap reachable through a documented flag. `--dsn` must default uncapped and a reached cap must never print `chain verified`. **Hole B**: a swallowed page error treated as EOF truncates → prefix false pass; errors must abort, and a mandatory `len(set) == snapshot count` cross-check must backstop every truncation path.

2. **OpenReadOnly coercion — migration impossible (verified: no `migrate.Run`, `CurrentVersion` is write-free probes only), but writing is discipline-only today.** modernc v1.50.1 opens every connection `READWRITE|CREATE` (conn.go:59-63); `mode=ro` is honored only for `file:` URIs — plain paths have the query stripped (conn.go:29-37), so the "append ?mode=ro" help text is a silent no-op. The returned Sink's `Record`/`RecordBatch`/`Prune` would write on such a handle, and a missing plain path creates an empty file before failing schema check. Fix: `OpenReadOnly` must normalize to `file:` URI + `mode=ro`, reject `immutable`/`nolock`, and add `_pragma=query_only(1)` as a driver-level second layer.

3. **Concurrent writes — false pass requires truncation; false fail requires skips.** Proven: appends during offset paging produce boundary *duplicates* (chain still verifies — inflated N/L1), deletes produce boundary *skips* (chain break — false fail). Both dissolve with one pinned read-only transaction (WAL snapshot; modernc honors `TxOptions.ReadOnly`, tx.go:23) with `ts DESC, rowid DESC` ordering (LastHash's existing tie-break). The only irreducible false fail is multi-writer ts inversion — must be documented as a single-writer-attestation limitation.

4. **WAL read-only lock failures — must be a distinct operational class.** CANTOPEN/busy/malformed-wal failures must never print `chain BROKEN` or exit 0; today exit 1 is shared between load errors and tamper (auditverify/main.go:98-103). Recommend exit 3 for store errors in `--dsn` mode, `_pragma=busy_timeout(5000)` (mattn-style `_busy_timeout` is a no-op, migrate.go:197-199), and rejecting `immutable=1` (skips the `-wal` → stale-prefix false pass).

5. **L1 token_issued divergence — must come from an independent same-snapshot COUNT, not the paged set** (a set-derived count agrees with a truncated set by construction, and `audit-export`'s `EventCount` shares that blind spot). The seam exists: `Facets(Query{Type: EventTokenIssued}).Total` (sqlite/query.go:119-165). Combined with the completeness cross-check, divergence is detected by construction; the parity pin `TestRun_DSN_TokenIssuedL1CountMatchesVolume` should assert L1 == recorded volume == export EventCount.
