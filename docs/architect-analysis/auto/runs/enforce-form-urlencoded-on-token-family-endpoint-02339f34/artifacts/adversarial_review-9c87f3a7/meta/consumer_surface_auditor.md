## 2. M4/M6 coverage verdict — two gaps

**M4 (migrate 35 JSON sites): complete for test/.** I independently re-derived the surface: 33 `http.Post(…, "application/json", …)` sites across the same 14 files (exact file:line match with the spec), plus the 2 `NewRequest`+`Header.Set` sites at `handle_introspect_test.go:202` and `introspect_batch_signed_test.go:248` (confirmed at `:245-248`). No additional JSON/no-CT post to the four endpoints exists in `test/`.

**Gap 1 — `docs/examples/quickstart/main.go:164` is not covered by M4 or M6.** The design never mentions it. It is the single in-tree non-test JSON consumer and will 400 after enforcement. `make examples` only *builds* it (`go build ./docs/examples/...`), so CI won't catch it — a user running the quickstart will. Fix: extend M4 (or add an M4b): keep `postJSON` for `/auth/login`, switch the `/token` exchange to `url.Values{…}.Encode()` with `application/x-www-form-urlencoded` (payload is flat strings, so no multi-value handling needed).

**Gap 2 — the OpenResty static SDK tree is not covered by M6/M7, and cannot be regenerated by any in-tree command.** Verified facts:

- `ops/deploy/openresty/fullstack/static/` is **entirely untracked** (`git status` shows `?? …/static/`, `git ls-files`/`git log --all` empty; nothing in `.gitignore`). Only the Dockerfile/nginx/lua/k8s files under `fullstack/` are tracked.
- The static `docs/sdks/client.ts`/`client.py` are **stale snapshots from an older gensdk generation** (12 ops vs 20 live, header "Minimal, hand-scoped", `JSON.stringify` at `client.ts:636`, `json.dumps` at `client.py:448`, no `clientAuth` flag). They currently emit JSON for all four ops.
- The static `docs/openapi.yaml` is a stale snapshot too: it still declares form+JSON for `postIntrospect` (`:971-991`), `postRevoke` (`:1047-1054`), `postPAR` (`:1177-1184`), plus the `localhost:8080` servers entry (`:52-54`).
- No in-tree script, Makefile target, or CI workflow references `fullstack/static`; the site is produced by an external docs-site generator ("ln v1.6.4" in the HTML meta). `python cli.py sdk-surface generate` writes only `docs/sdks/*`.

So the honest resolution is explicit scoping in the design: (a) M6/M7 changing `cmd/gensdk` + `docs/openapi.yaml` is what makes the external pipeline emit form clients on its next run — "regenerated in the same change" holds at the source level since static/ has nothing to commit; (b) the design should state that the static tree is an untracked deploy artifact refreshed by that external pipeline, and that its openapi copy carries the same C4 JSON siblings, which the C4 edits flow through only if the pipeline re-copies the spec — otherwise the static copy must be hand-refreshed in the same change. Either way it needs an explicit sentence, not silence.
