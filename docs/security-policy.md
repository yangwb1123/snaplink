# Security Policy Pointers

This file intentionally does not duplicate response times, reporting channels
or supported-version statements.

- The authoritative vulnerability-reporting policy is
  [`.github/SECURITY.md`](../.github/SECURITY.md). GitHub discovers that path
  automatically.
- The implementation-oriented threat model, hardened areas, fail-mode matrix
  and deployment checklist are in [SECURITY.md](SECURITY.md).
- Wire error behavior is catalogued in
  [error-codes.md](error-codes.md).

If these documents appear to disagree, `.github/SECURITY.md` controls reporting
policy and `AGENTS.md` §3 controls implementation invariants.

Do not open a public issue for a suspected vulnerability. Use the private
channel described in `.github/SECURITY.md`.
