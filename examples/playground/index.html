Login & Tokens

    

      
Password Login POST

      
Direct-mint flow: validates credentials and returns access_token + id_token (captured above for reuse).

      

        
        
        
      

      
      

    

    

      
UserInfo GET

      
OIDC UserInfo — uses the captured access_token as Bearer.

      
      

    

    

      
Introspect POST

      
RFC 7662 — client (Basic auth) asks whether the captured token is active.

      
      

    

    

      
Refresh POST

      
RFC 6749 §6 — single-use rotation; returns a new access_token + rotated refresh_token.

      
      

    

    

      
Revoke POST

      
RFC 7009 — 200 on valid client creds regardless of token existence (anti-enumeration).

      
      

    

  


  
Authorization Code + PKCE

    

      
Code flow (S256) POST×2

      
Generates a PKCE verifier/challenge, requests an authorization code at /auth/login (response_type=code), then exchanges it at /token.

      
      

    

  


  
Device Flow

    

      
Device Authorization POST

      
RFC 8628 — request device_code + user_code, then poll /token.

      
      
      

      

    

  


  
Pushed Authorization Request

    

      
PAR POST

      
RFC 9126 — push the authorization params server-side, get a request_uri back (Basic client auth).
